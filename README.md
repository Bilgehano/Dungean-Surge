# Dungeon Surge

This repository is organized into three main parts:

- [src](src): the Unity game project
- [GameManuel](GameManuel): the game manual and LaTeX source
- [Abschluss_Presentation](Abschluss_Presentation): the presentation material

## Open The Game In Unity

Clone the repository, then open [src](src) in Unity Hub or the Unity Editor.

- Unity project folder: [src](src)
- Recommended editor version: `6000.4.1f1`
- Unity will regenerate local folders like `Library` automatically

Important: do not open the repository root as the Unity project. Open [src](src) directly.

## Folder Overview

### [src](src)

Contains the playable game source, assets, packages, and project settings.

### [GameManuel](GameManuel)

Contains the illustrated game manual.

### [Abschluss_Presentation](Abschluss_Presentation)
